# Prediksi OSN Informatika 2026

Repositori ini berisi halaman web statis untuk menampilkan prediksi peringkat OSN Informatika 2026 berdasarkan data hasil OSN 2025, status kelayakan peserta, kelas tahun 2026, serta beberapa referensi pendukung lainnya.

## Isi Proyek

- Prediksi peringkat peserta OSN Informatika 2026
- Prediksi medali: emas, perak, perunggu
- Informasi sekolah/alma mater
- Informasi provinsi
- Tautan referensi pendukung

## Sumber Referensi

Beberapa referensi yang digunakan dalam penyusunan prediksi antara lain:

- Hasil OSN Informatika 2025
- Open results OSN 2025
- Hasil final Liga Kompetitif Indonesia musim #1
- Referensi pendukung lain yang relevan
